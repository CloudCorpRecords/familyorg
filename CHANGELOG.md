# Changelog

## 0.1.0 (2026-10-26)

- First release: the full documented 15-tool surface of the unofficial
  Cozi client (family members, shopping and to-do lists and items,
  shared calendar with appointments and search) against the Cozi REST
  API, as CLI + stdio MCP server in one bin. COZI_READ_ONLY=true hides
  the nine write tools; `today` is a pure local clock.
